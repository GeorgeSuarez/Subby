2 Data layers — reads flow up, writes flow down

Dependencies only point downward: features → store → db → SQLite. The store is a read-through cache: after any write it re-reads every row instead of patching arrays locally — the cache can never drift from the database.

4 Auth & password flows

A pure state machine (src/features/auth/auth-flow.ts) decides which form the reset screen shows: entry | verify | recovery | change.

↺ Reset flow (signed out)

entry Forgot password → request code
recovery Enter 6-digit code (Mailpit locally) or paste magic link
session Recovery session granted — recoveryPending, skips current-password check
change Set new password → signed in 🎉

✎ Change flow (signed in)

verify Verify current password
handoff Redirect to ?from=settings&verified=1
change New password form → updated ✅
The handoff is a URL contract because the app reloads mid-flow inside Expo Go — state survives via route params, not memory.
