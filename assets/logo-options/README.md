## Ledger Stack

- `ledger-stack.png`
- `ledger-stack.svg`

The selected mark uses three staggered subscription rows. Each row represents a recurring expense or service, while the cadence dots make the individual billing records legible at small sizes.

The app uses this mark across the app icon, splash screen, favicon, Android adaptive icon, Android monochrome icon, iOS Icon Composer asset, and auth brand lockup.
